Screencast 0.2.6 for Windows 11 x64.

- Icon variants are rendered separately from vector geometry with alpha-aware area coverage, replacing bicubic shrinking of a large raster master. This keeps small contours sharper without changing the artwork or composition.
- The ICO now includes 22 native sizes from 16 to 256 pixels, including intermediate Windows scaling sizes and the installer's 112-pixel image. The lossless 2048-pixel source is included.
- Application, installer, desktop, Start menu and uninstall shortcuts share the same updated artwork. A new versioned icon path refreshes shortcut references during installation.
- Recording features and the single-instance guard remain unchanged.
