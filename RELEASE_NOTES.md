# Screencast 0.5.0

- Soulu / Connect light and dark themes, unchanged Montserrat and three-column recording controls.
- Settings open from a right-click on empty titlebar/workspace and slide down from the top, with a blurred backdrop. Capture continues while settings are open.
- Theme, RU/EN and MP4 folder are saved automatically. About includes the build version, release page and by connect. link.
- Recording starts without a file dialog, using a unique Screencast_YYYY-MM-DD_HH-MM-SS.mp4 name. Folder access and free space are checked before capture.
- Recoverable MP4 material and its location are reported on recording/finalization errors.
- Windows Start Menu uses one Screencast shortcut at the root. Updates remove the old application/uninstall shortcuts and empty folder. Removal remains available in Windows Installed Apps.

The existing capture, audio, camera and background pipelines are preserved.
