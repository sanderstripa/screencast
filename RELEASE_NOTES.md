Screencast 0.2.2 for Windows 11 x64.

- Camera and microphone can be switched on/off while recording, including recordings started with them disabled. Disabled capture devices are released.
- New live Mirror switch changes webcam orientation in the desktop circle and recorded window composition.
- Mouse clicks on theme buttons no longer add a rectangular focus artifact; keyboard focus uses a rounded outline.
- Decoded MP4 checks cover camera visibility, ordinary/mirrored orientation and independent microphone/system audio.

Download Screencast-Setup-x64.exe for installation or Screencast-Windows-x64.zip for portable use. Background processing uses a separately downloaded local model (about 15 MB).
