Screencast 0.2.1 for Windows 11 x64.

- Fixed application flicker: buffered painting, child clipping and no repeated full-window repaints while idle.
- Fully custom installer window with integrated minimize/close buttons and no system title strip.
- Blue enabled switches and grey disabled switches in both themes.
- Vertically centered installation path and browse button.
- Launch option appears only on completion, as a centered circular checkbox; Cancel is removed from this page.
- Russian/English switching and light/dark themes retained.

Download Screencast-Setup-x64.exe for installation or Screencast-Windows-x64.zip for portable use. Background processing uses a separately downloaded local model (about 15 MB).
