Screencast 0.2.3 for Windows 11 x64.

- Removed additional focus outlines from all app controls in both themes.
- Enlarged icon artwork within every icon size, including the Windows taskbar.
- Camera prefers a supported 720p/30 mode. Background effects retain the original camera resolution and detail; only the silhouette model input remains small.
- Smooth bilinear sampling replaces pixelated nearest-neighbor resizing in the webcam circle, preview and background composition.
- Existing live source controls and mirror mode retained.

Download Screencast-Setup-x64.exe for installation or Screencast-Windows-x64.zip for portable use. Background processing uses a separately downloaded local model (about 15 MB).
