Screencast 0.2.0 for Windows 11 x64.

- Floating, draggable webcam circle visible on the desktop, screenshots and recordings.
- Background effects can be downloaded directly from the app; no manual commands.
- Compact three-column interface without scrolling; corrected theme-aware switches.
- Faithfully redrawn application icon, embedded in the app, setup and shortcuts.
- Native per-user installer with Russian/English language switching and light/dark themes.
- Independent live audio levels, adjustable spectral noise suppression, background blur and calm built-in backgrounds.

Download Screencast-Setup-x64.exe for installation or Screencast-Windows-x64.zip for portable use. Background processing uses a separately downloaded local model (about 15 MB).
